# ahp-consistency-analysis
A Python tool for checking consistency of AHP pairwise comparison survey data using Saaty's eigenvalue method.

This script analyses Analytic Hierarchy Process (AHP) pairwise comparison survey data for internal consistency. It computes the Consistency Ratio (CR) for each respondent using the eigenvalue method and Saaty's Random Index table, and detects intransitive judgment triads. Results are summarised at the respondent, role, and category level and exported to CSV. The tool was developed as part of methodology work for an Horizon Europe Co-funded research project, SDG-BASED, on sustainability rating systems (project code CETP-FP-2023-00229) by CitySync Solutions AB, and was built with assistance from Claude (Anthropic).
